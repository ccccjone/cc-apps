当时要定：掌机外形和「整屏触控」两种模式怎么并存，六款游戏各自怎么操作。结果：这一轮进游戏后仍是单色方块，被我否掉，转去第三轮；掌机模式保留为默认，整屏触控推迟到以后。

The question: how a handheld layout and a full-screen touch mode could coexist, and how each of the six games would be controlled. Outcome: inside the games this round still showed single-color blocks, so I rejected it and moved to round 3. The handheld layout stayed as the default; full-screen touch was postponed.

卡带掌机双屏模式
方案 C · 卡带 · 第二轮

默认掌机，一键切大屏

这一版的手机按 iPhone 17 的真实尺寸（402×874 pt）画，屏幕里的点阵是从游戏逻辑导出的真实帧，所以大小可以直接对照。

第一轮的图把屏幕画小了。按真实比例排版后，掌机模式的屏幕其实不算小。大屏模式主要是变宽：iPhone 是宽度先用满，所以细长的游戏（贪吃蛇、方块消除、打砖块）放大明显，接近方形的游戏（2048、推箱子）只大一点。

你的想法我照着做了：默认是 C 的掌机小屏，右上角一个按钮切到大屏，大屏用触屏操作。

两种模式怎么切

点下面的按钮看切换效果。切换时按键收起、屏幕放大，游戏不会暂停，也不会重开。

游戏里：右上角的放大按钮

在暂停按钮旁边，点一下切换。每款游戏单独记住上次用的模式，比如 2048 可以一直用大屏，贪吃蛇一直用掌机。

设置里：新游戏默认用哪种

“游戏设置”里新增“屏幕模式”一项，决定没玩过的游戏第一次打开时用哪种，默认是掌机。

大屏怎么操作

方向键改成在屏幕上滑动。A、B 键按功能处理：能用手势代替的就用手势（比如方块消除轻点旋转），代替不了的留成屏幕下方的文字按钮（比如 2048 的撤销）。前几局会显示手势提示。

代码怎么改

只改 App 层。大屏的手势最终还是转换成现有的 GameInput 输入，Kit 层的六款游戏不需要改动。

其他页面

首页、暂停、设置

首页左右滑动换卡带，封面用的是真实帧。暂停菜单是屏幕里的像素对话框，用十字键选择、A 键确认，也可以直接点。设置页新增“屏幕模式”一项。

需要你定

几个待确认的点

1. 大屏是否保留实体按钮。目前只有“撤销、重开、变速”这类操作留成按钮，方向全部改成滑动。如果你更想要屏幕下方有一排半透明方向键，我可以加一个变体。

2. 贪吃蛇的大屏手势。贪吃蛇连续快速转向时，滑动比按键容易误判，大屏玩贪吃蛇的手感需要在真机上试。

3. 月光配色。这版用深夜蓝底加薄荷色像素，打算作为第四套主题，也做成默认主题。现有三套主题只换像素颜色，可以在顶部切换看效果。

确认以后，我就把 C 和双模式写成正式规格，然后按项目流程拆计划。
